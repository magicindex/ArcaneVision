# 富文本打开方式关联（0.8.5）

## 背景

0.8.4 及更早的「打开方式关联」只有「文本」和「代码」两组：

- 文本：`txt`、`md`、`markdown`、`log`、`ini`、`conf`、`cfg`、`toml`、`rst`
- 代码：`html`、`htm`、`json`、`xml`、`css`、`yaml` 等
- `rtf` 在「文字文档」里，默认走文档服务

这样同一类「用来看的富文本」被拆到三组，用户要分别设置；RTF 在没有文档服务时只能下载。

## 0.8.5 的「富文本」组

设置 → 打开方式关联 → **富文本**，覆盖：

```
txt text rtf md markdown mdown mkd mdx html htm xhtml shtml
json jsonc xml xsl log ini conf cfg toml rst tex nfo
```

可选打开方式：

| 值 | 名称 | 行为 |
| --- | --- | --- |
| `rich`（默认） | 内置富文本（Markdown/HTML 渲染） | 按扩展名分派，见下 |
| `docs` | 文档服务 | 交给飞牛「文档」应用（RTF/Office 最合适） |
| `preview` | 浏览器直接打开 | 同样走内置富文本；HTML 不会裸渲染 |
| `fnpreview` | 在线预览（应用中心） | 交给 `/app/trim-preview/` |
| `download` | 下载文件 | 直接下载 |

### 内置富文本的分派

- `.md/.markdown/.mdown/.mkd`：`/api/markdown` 服务端渲染，保留明暗主题；
- `.html/.htm/.xhtml/.shtml`：清洗后在 sandbox iframe 里渲染；
- `.rtf`：检测到文档服务时交给文档服务；没有文档服务时用内置 RTF 纯文本解析；
- 其余：`/api/text` 文本查看（带下载按钮与「按文档查看」）。

## HTML 渲染细节

HTML 来自用户文件，不能直接以同源页面加载，否则文件里的脚本可以拿到玄览的 Cookie/权限。
0.8.5 的处理：

1. `fetch` 文件字节，按 BOM 与 `<meta charset>` 识别编码（支持 GBK/GB18030/Big5 等旧页面）；
2. `DOMParser` 解析后清洗：
   - 移除 `script/iframe/object/embed/form/input/button/textarea/select/link/meta/base/
     video/audio/source/canvas/svg/math`；
   - 去掉所有 `on*` 事件属性、`srcset`、`formaction`；
   - `href` 只保留 `http(s)` 外链（新标签打开），相对链接去掉；
   - `<img src>` 按 HTML 文件所在目录解析，重写成 `/api/file?path=...`；
   - `<style>` 里的 `@import`、`expression()`、`javascript:` 去掉，`url(...)` 相对资源同样
     重写为 `/api/file?path=...`；外链样式表整段丢弃；
3. 生成文档带 CSP：
   `default-src 'none'; img-src 'self' data:; style-src 'self' 'unsafe-inline'; font-src 'self' data:`
4. 放进 `sandbox="allow-same-origin allow-popups"` 的 iframe（不允许脚本）。

因此即使设置了「浏览器直接打开」或「新窗口」，HTML 仍然走沙箱渲染——这是有意为之，
避免为了一个预览动作把整个应用的同源权限交给任意 HTML 文件。

## RTF 纯文本解析

没有文档服务时的兜底，处理：

- 跳过 `fonttbl/colortbl/stylesheet/info/pict/object/header/footer/field/...` 等目标组；
- `\par`、`\line` → 换行，`\tab` → 制表符；
- `\uN?` → Unicode 字符（含负数映射），`\'hh` → 单字节字符；
- `\emdash/\endash/\lquote/\rquote/\ldblquote/\rdblquote/\bullet` 等符号；
- `\b/\i/\fsN` 等排版控制字忽略。

输出是纯文本（标签显示「RTF · 纯文本」），不保留粗体、字号、表格等格式；需要完整排版时
安装「文档」应用并把富文本打开方式设为「文档服务」。

## 兼容性

- 旧设置里的 `openWith.text` 会自动作为「富文本」的值使用；保存一次后写入 `openWith.rich`。
- 「代码」组保留 `css/scss/vue/svelte/yaml/yml` 等真正的代码扩展名；`html/json/xml` 移到
  富文本组。
- 「文字文档」组移除 `rtf`，避免同一个扩展名出现在两个下拉里。

## 验证

- 设置面板：出现「富文本」行，选项为 内置富文本 / 文档服务 / 浏览器直接打开 / 在线预览 / 下载。
- HTML 样例（含 `<script>`、`onerror`、`onclick`、外链、相对图片）：
  - 渲染后 `script` 数量 0、`on*` 属性 0；
  - 图片重写为 `/api/file?path=/tmp/pic.png`；
  - CSP 存在，外链保留 `target=_blank`；
- Markdown：iframe 指向 `/api/markdown?path=...`；
- TXT/JSON：iframe 指向 `/api/text?path=...`；
- RTF 样例（`\b`、`\par`、`\u20013?\u25991?`、`\'e9`）：输出 `Hello bold 中文 é`。
