# 多词搜索

0.10.7 增加文件名声明的多词检索。默认开启，多个关键词需要同时命中；可在
「设置 → 高级搜索」切换为任一命中，并配置分隔符、大小写和顺序。

## 语法

### 空格分隔

```text
量子 计算
```

文件名同时包含「量子」和「计算」才返回；默认不要求顺序，`量子计算指南`、
`计算 量子`、`量子 研究 计算` 都命中。

### 精确词组

```text
"量子 计算"
```

引号内的空格保留，作为一个连续词组的精确子串；只命中文件名中出现连续
「量子 计算」的文件。

### 逗号分隔

设置分隔方式为「空格或逗号」后：

```text
量子,计算
alpha,beta
```

与空格分隔等价；中文逗号 `，` 也支持（UTF-8 分隔符按完整字符跳过）。

### 任一命中

设置「多词关系」为「单一命中」后：

```text
alpha beta
```

文件名包含 `alpha` 或 `beta` 任一即返回。

## 设置项

| 设置 | 默认 | 说明 |
|---|---|---|
| 启用多词搜索 | 开启 | 关闭后整个输入作为单一子串查询 |
| 多词关系 | 同时命中 | 同时命中=全部词；单一命中=任一词 |
| 关键词分隔 | 空格 | 空格 / 空格或逗号 / 空格或换行 |
| 区分英文大小写 | 关闭 | 只影响英文 ASCII；中文不受影响 |
| 按出现顺序匹配 | 关闭 | 同时命中时要求词按输入顺序出现 |

对应 `/api/settings` 字段：

```json
{
  "searchMulti": true,
  "searchMatchAll": true,
  "searchSeparator": "space",
  "searchCaseSensitive": false,
  "searchOrdered": false
}
```

`searchSeparator` 取值：`space`、`comma`、`line`。

## API

```http
GET /api/search?q=alpha%20beta&limit=50
GET /api/search?q=%22alpha%20beta%22&limit=50
```

- 匹配目标是文件名，不是完整路径；
- 单次查询最多 512 字节、最多 32 个词；
- 少于 3 个字符的词会走名字池扫描，速度较慢；
- 多词「同时命中」用最长词生成候选，其余词逐个复核；
- 「单一命中」分别查询每个词后合并去重；
- 顺序匹配只对「同时命中」生效。
